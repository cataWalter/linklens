## [Unreleased]

### Added
- Initial project structure
- Multi-language parser support (JavaScript, TypeScript, Python, Java, C, C++, Go, Rust, PHP, Ruby)
- Interactive dependency graph visualization with Cytoscape.js
- File tree sidebar for navigation
- Metrics panel with coupling, cohesion, and instability calculations
- Cycle detection using Kosaraju's algorithm
- Hub and orphan file identification
- File system watcher for hot reload
- Dark/light theme support
- Export to PNG, SVG, and JSON
- Filter by language, search, and graph properties
- Multiple graph layouts (Dagre, COSE-Bilkent, Grid, Circle, Concentric)
- GitHub Actions CI/CD pipeline
- Unit and E2E testing infrastructure
